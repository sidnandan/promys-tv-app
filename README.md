# Promys-Tv

A player for your own IPTV playlist, on Android phones and on Fire TV, Android TV and Google TV.
It ships no channels, films or series of its own: you add the playlist your provider gave you.

## Installing it

The app is not on the Play Store, so it updates through **Obtainium**, which watches this page and tells
you when there is a new version.

**On a phone**

1. Install [Obtainium](https://github.com/ImranR98/Obtainium/releases/latest) (tap the `.apk` there).
2. Open Obtainium, tap **Add App**, and paste:
   `https://github.com/sidnandan/promys-tv-app`
3. Tap **Add**, then **Install**. Android will ask whether to allow installing from Obtainium — say yes.

**On a Fire TV or Android TV**

1. Install the **Downloader** app from your TV's own store, and allow it to install apps.
2. In Downloader, open `https://github.com/sidnandan/promys-tv-app/releases/latest` and pick the `.apk`.
3. For later updates, install Obtainium the same way and add the address above.

## Signing in

Open **Settings → Your profile → Create a profile**. You need the invite word Sid gave you. Your profile
keeps your playlists, where you stopped watching, what you have finished, your lists and your favourite
channels the same on every device you sign in on — and nobody else can see any of it.

Add your email while you are there: it is used for one thing only, a link to set a new password if you
forget yours.

## What each release is

Every release here is built from the private source repository and signed with the same key, so updates
install over the last one. The newest release is the one to have.
